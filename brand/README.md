# Brand assets

The mark is a cross-section: a waterline, a hull basin hanging from it, a keel
spine, and a coral ballast bulb at the bottom. The reasoning behind it is in
[`design-philosophy.md`](design-philosophy.md).

Everything here is generated by [`generate.py`](generate.py) from a single
`keel_mark()` function. **Edit the geometry there, never an exported PNG** — the
whole point of the mark is that one stroke gauge and one set of intervals hold at
every size, and hand-editing an export breaks that silently.

## Files

| File | Size | Use for |
| --- | --- | --- |
| `avatar-dark.png` | 1024×1024 | **GitHub org avatar**, app icons, anywhere square |
| `avatar-light.png` | 1024×1024 | Square mark on dark surfaces (slide decks, dark UI) |
| `banner-social.png` | 1280×640 | GitHub social preview, OG/Twitter card, README header |
| `wordmark-transparent.png` | 1600×520 | Lockup on **light** backgrounds (navy ink) |
| `wordmark-transparent-cream.png` | 1600×520 | Lockup on **dark** backgrounds (cream ink) |

### Two wordmarks, on purpose

A transparent asset carries no background, so it cannot guarantee its own
contrast. The navy wordmark is invisible on a dark surface — including a
dark-theme GitHub README, which is roughly half of visitors.

Use the pair together:

```html
<picture>
  <source media="(prefers-color-scheme: dark)"
          srcset="https://raw.githubusercontent.com/keelapps/.github/main/brand/wordmark-transparent-cream.png">
  <img alt="keelapps"
       src="https://raw.githubusercontent.com/keelapps/.github/main/brand/wordmark-transparent.png"
       width="320">
</picture>
```

`banner-social.png` and both avatars carry their own background, so they need no
such handling.

### Picking an avatar

Use **`avatar-dark.png`** for the GitHub org avatar. The cream background of
`avatar-light.png` is `#F4EFE6` against GitHub's `#ffffff` light theme — close
enough that the avatar's edge disappears and the mark appears to float. The navy
plate holds its shape on both themes.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Navy | `#0F2536` | Ink on light, ground on dark. Sounding-chart navy — water at forty fathoms |
| Cream | `#F4EFE6` | Ground on light, ink on dark. Chart paper |
| Coral | `#E8664A` | The ballast bulb. **One drop only** |
| Navy soft | `#1C3A52` | Above-waterline tint on dark plates, 35% opacity |
| Cream soft | `#E5DECF` | Above-waterline tint on light plates, 35% opacity |

Coral is a signal, not a colour in the palette. It marks the ballast point and
nothing else — the smallest element carrying the warmest colour is the whole
idea. Do not use it for links, buttons, or emphasis.

## Type

- **Outfit Bold** — wordmark, headings
- **Geist Mono** — station labels (`st.00`, `wl +0`) and engineer's marginalia only

Both are OFL-licensed. `generate.py` needs them installed to render text; without
them cairosvg silently substitutes a default face and the wordmark comes out
wrong, with no error. Set `FONT_SRC` to a directory containing
`Outfit-Bold.ttf`, `Outfit-Regular.ttf` and `GeistMono-Regular.ttf`.

## Regenerating

```bash
pip install cairosvg
FONT_SRC=/path/to/fonts python3 generate.py        # writes into this directory
```

The script reproduces all five committed PNGs byte-for-byte, so a clean checkout
plus a run should leave `git status` empty. If it does not, something in the
toolchain drifted — investigate before committing the new bytes.

## Don't

- Recolour the mark outside the palette above
- Add shadows, gradients, glows, or outlines
- Change the stroke weight relative to the mark, or scale the parts unevenly
- Rotate the mark, or move the waterline off horizontal
- Put the wordmark on a busy photo — it has no container and will not survive it
- Use coral for anything other than the ballast bulb
